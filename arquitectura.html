MAPA DEL SISTEMA

Cómo funciona el bot de ofertas

El proceso completo, de punta a punta: de las 5 fuentes hasta el panel que abrís vos. Después de ver el mapa general, entramos parte por parte a definir los criterios exactos de cada etapa.

Las 7 etapas, en detalle para cuando entremos parte por parte

  • Fuentes — sites.py

    Qué cadenas se consultan y con qué IDs de categoría de bebidas en cada una. Carrefour, Vea, Día y Changomas exponen una API pública (VTEX); Vital no tiene tienda online, solo folletos PDF por sucursal.

  • Extracción — vtex_client.py / vital_scraper.py

    Trae los productos crudos de cada fuente. Para VTEX es un único cliente reutilizado 4 veces; Vital tiene su propio scraper porque su estructura es distinta (HTML con links a PDF, no una API de productos).

  • Criterio de oferta — dentro de vtex_client.py

    Define qué cuenta como oferta real: precio actual por debajo del precio de lista (con un tope de 70% de descuento para descartar precios de lista mal cargados), o una promo explícita con etiqueta (2x1, 3x2, "X% off") aunque el precio de lista esté roto o no cambie.

  • Comparación con ayer — freshness.py

    Compara la corrida de hoy contra estado_ofertas.json (lo que se guardó ayer): marca qué ofertas son nuevas o mejoraron, y si una cadena trae muchas menos ofertas que su máximo histórico, la marca como "posible fuente rota" en vez de mostrarla como "sin ofertas".

  • Clasificación — export_data.py

    Ordena cada cadena: lo nuevo/mejorado primero, después por % de descuento. Agrupa por cadena y guarda todo en offers_snapshot.json.

  • Panel visual — build_dashboard.py

    Convierte ese JSON en el HTML autocontenido que ves: tarjetas por cadena, precios tachados, etiquetas NUEVO, avisos de fuente rota.

  • Publicación + automatización — rutina diaria en la nube

    Todos los días a las 10:00, una rutina clona el repositorio, corre las 6 etapas anteriores, republica el panel en la misma URL, y guarda de vuelta el estado actualizado para que mañana el proceso tenga memoria de hoy.
